Mindora Backend API Documentation

Base URL: http://localhost:5000/api
Auth: Include "Authorization: Bearer <token>" in Headers for protected routes.

==============================
1. AUTHENTICATION MODULE
==============================

👉 1. Send OTP
• Method: POST
• Route: /api/auth/otp/send
• Headers: Content-Type: application/json
• Body:
{
  "email": "user@example.com"
}
• Response (200):
{
  "success": true,
  "message": "Verification code sent to your email."
}

👉 2. Verify OTP & Login
• Method: POST
• Route: /api/auth/otp/verify
• Headers: Content-Type: application/json
• Body:
{
  "email": "user@example.com",
  "otp": "823593",
  "name": "Ishan Mittal"
}
• Response (200):
{
  "success": true,
  "token": "eyJhbGciOi...",
  "user": {
    "id": "670c5e3d...",
    "name": "Ishan Mittal",
    "email": "user@example.com",
    "authProvider": "otp"
  }
}

👉 3. Guest Login
• Method: POST
• Route: /api/auth/guest
• Headers: Content-Type: application/json
• Body: {}
• Response (200): Returns token & guest user object.

==============================
2. MOOD TRACKING (Protected)
==============================

👉 1. Log / Update Daily Mood (Upsert)
• Method: POST
• Route: /api/mood/entry
• Headers: 
  - Authorization: Bearer <token>
  - Content-Type: application/json
• Body:
{
  "date": "2026-10-15",
  "mood": "good",
  "intensity": 4,
  "note": "Working on frontend integration",
  "tags": ["coding", "productive"]
}
(Allowed mood values: terrible, bad, neutral, good, rad)
• Response (200): Returns saved mood entry.

👉 2. Monthly Calendar View
• Method: GET
• Route: /api/mood/calendar?year=2026&month=10
• Headers: Authorization: Bearer <token>
• Response (200): Chronological array of entries for that month.

👉 3. Yearly Heatmap (GitHub Style)
• Method: GET
• Route: /api/mood/heatmap?year=2026
• Headers: Authorization: Bearer <token>
• Response (200):
{
  "success": true,
  "year": "2026",
  "totalEntries": 2,
  "data": {
    "2026-10-02": { "mood": "good", "intensity": 4 },
    "2026-10-15": { "mood": "rad", "intensity": 5 }
  }
}

==================================
3. GOOGLE AUTHENTICATION ENDPOINT
==================================

👉 Google Login / Signup
• Method: POST
• Route: /api/auth/google
• Headers: 
  Content-Type: application/json
• Body:
{
  "token": "<google_id_token_from_frontend>"
}

• Success Response (200 OK):
{
  "success": true,
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "670c5e3d1234567890abcdef",
    "name": "Ishan Mittal",
    "email": "user@gmail.com",
    "authProvider": "google"
  }
}

• Error Responses:
  - 400 Bad Request:
    { "error": "Google ID token is required" }
  - 401 Unauthorized:
    { "error": "Google authentication failed" }

6. MINDORA BACKEND: COPING & ML API SPECIFICATIONS
==================================================

Base URL: https://mindora-backend-mdfl.onrender.com

--------------------------------------------------
1. Coping ML Health Check
--------------------------------------------------
• Method: GET
• Endpoint: /api/ml/coping/health
• Access: Public (No Token Required)
• Purpose: Check if the underlying ML recommendation engine is alive and ready.
• Response (200 OK):
  {
    "success": true,
    "mlService": {
      "status": "ok",
      "activities": 66,
      "threshold": 0.3
    }
  }
• Error Response (502 Bad Gateway):
  {
    "success": false,
    "error": "ML service is asleep or offline."
  }

--------------------------------------------------
2. Get Personalized Coping Recommendations
--------------------------------------------------
• Method: POST
• Endpoint: /api/ml/coping/recommend
• Access: Protected
• Headers:
    Authorization: Bearer <USER_JWT_TOKEN>
    Content-Type: application/json
• Request Body:
  {
    "mood": "stress",
    "mood_intensity": 4,
    "energy_level": 3,
    "time_of_day": "evening",
    "top_n": 3
  }

• Constraints & Valid Values:
    - mood (string, required): 
      "stress" | "anxiety" | "frustration" | "sadness" | "low_energy" | "overwhelmed" | "loneliness" | "restlessness"
    - mood_intensity (integer, optional, default: 3): 1 to 5
    - energy_level (integer, optional, default: 3): 1 to 5
    - time_of_day (string, optional, default: "evening"): 
      "morning" | "afternoon" | "evening" | "night"
    - top_n (integer, optional, default: 3): 1 to 10

• Success Response (200 OK):
  {
    "success": true,
    "recommendations": [
      {
        "activity_id": "act_04",
        "title": "Box Breathing",
        "category": "breathing",
        "description": "4-4-4-4 rhythm for nervous system regulation",
        "duration_min": 5,
        "score": 0.82,
        "predicted_helpful": true,
        "repeated_recently": false
      }
    ],
    "threshold": 0.3
  }

• Validation Error (400 Bad Request):
  {
    "success": false,
    "error": "Invalid mood. Allowed moods are: stress, anxiety, frustration, sadness, low_energy, overwhelmed, loneliness, restlessness"
  }

5. Activity Feedback (Logging Completion/Rating)
--------------------------------------------------
• Method: POST
• Endpoint: /api/ml/coping/feedback
• Access: Protected
• Headers:
    Authorization: Bearer <USER_JWT_TOKEN>
    Content-Type: application/json
• Request Body:
  {
    "activity_id": "act_04",
    "action": "completed",
    "rating": 5
  }
• Constraints:
    - action: "completed" | "dropped" | "skipped"
    - rating: integer 1 to 5 (required only when action is "completed")
• Success Response (201 Created):
  {
    "success": true,
    "feedback": {
      "id": "671cb2f...",
      "activity_id": "act_04",
      "action": "completed",
      "rating": 5,
      "createdAt": "2026-10-26T14:15:00.000Z"
    }
  }
