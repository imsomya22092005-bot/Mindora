Mindora Backend API Documentation

Base URL: http://localhost:5000/api
Auth: Include "Authorization: Bearer <token>" in Headers for protected routes.

==============================
1. AUTHENTICATION MODULE
==============================

👉 1. Send OTP
• Method: POST
• Route: /api/auth/otp/send
• Headers: Content-Type: application/json
• Body:
{
  "email": "user@example.com"
}
• Response (200):
{
  "success": true,
  "message": "Verification code sent to your email."
}

👉 2. Verify OTP & Login
• Method: POST
• Route: /api/auth/otp/verify
• Headers: Content-Type: application/json
• Body:
{
  "email": "user@example.com",
  "otp": "823593",
  "name": "Ishan Mittal"
}
• Response (200):
{
  "success": true,
  "token": "eyJhbGciOi...",
  "user": {
    "id": "670c5e3d...",
    "name": "Ishan Mittal",
    "email": "user@example.com",
    "authProvider": "otp"
  }
}

👉 3. Guest Login
• Method: POST
• Route: /api/auth/guest
• Headers: Content-Type: application/json
• Body: {}
• Response (200): Returns token & guest user object.

==============================
2. MOOD TRACKING (Protected)
==============================

👉 1. Log / Update Daily Mood (Upsert)
• Method: POST
• Route: /api/mood/entry
• Headers: 
  - Authorization: Bearer <token>
  - Content-Type: application/json
• Body:
{
  "date": "2026-10-15",
  "mood": "good",
  "intensity": 4,
  "note": "Working on frontend integration",
  "tags": ["coding", "productive"]
}
(Allowed mood values: terrible, bad, neutral, good, rad)
• Response (200): Returns saved mood entry.

👉 2. Monthly Calendar View
• Method: GET
• Route: /api/mood/calendar?year=2026&month=10
• Headers: Authorization: Bearer <token>
• Response (200): Chronological array of entries for that month.

👉 3. Yearly Heatmap (GitHub Style)
• Method: GET
• Route: /api/mood/heatmap?year=2026
• Headers: Authorization: Bearer <token>
• Response (200):
{
  "success": true,
  "year": "2026",
  "totalEntries": 2,
  "data": {
    "2026-10-02": { "mood": "good", "intensity": 4 },
    "2026-10-15": { "mood": "rad", "intensity": 5 }
  }
}

==================================
3. GOOGLE AUTHENTICATION ENDPOINT
==================================

👉 Google Login / Signup
• Method: POST
• Route: /api/auth/google
• Headers: 
  Content-Type: application/json
• Body:
{
  "token": "<google_id_token_from_frontend>"
}

• Success Response (200 OK):
{
  "success": true,
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "670c5e3d1234567890abcdef",
    "name": "Ishan Mittal",
    "email": "user@gmail.com",
    "authProvider": "google"
  }
}

• Error Responses:
  - 400 Bad Request:
    { "error": "Google ID token is required" }
  - 401 Unauthorized:
    { "error": "Google authentication failed" }

==============================
3. CALM CORNER (Protected)
==============================

👉 1. Log Mindful Session
• Method: POST
• Route: /api/calm/session
• Headers: 
  - Authorization: Bearer <token>
  - Content-Type: application/json
• Body:
{
  "activityType": "box_breathing",
  "durationMinutes": 5,
  "soundscape": "rain",
  "reflectionNote": "Felt grounded and calm after coding"
}
(Allowed activityType values: box_breathing, 478_breathing, ambient_sound, grounding, custom)
(Allowed soundscape values: rain, forest, waves, none)
• Response (201):
{
  "success": true,
  "message": "Session recorded successfully",
  "data": {
    "_id": "670c5e3d1234567890abcdef",
    "user": "670c4a1b...",
    "activityType": "box_breathing",
    "durationMinutes": 5,
    "soundscape": "rain",
    "reflectionNote": "Felt grounded and calm after coding",
    "completedAt": "2026-10-20T11:25:00.000Z"
  }
}

👉 2. Aggregate Dashboard Stats
• Method: GET
• Route: /api/calm/stats
• Headers: Authorization: Bearer <token>

{

4. MOVEMENT / MINDFUL PRACTICES MODULE
=======================================

👉 1. Get All Movement Cards
• Method: GET
• Route: /api/movements
• Headers: None (Public)
• Response (200):
{
  "success": true,
  "data": [
    {
      "id": "1",
      "slug": "desk-stretch",
      "title": "Desk Stretch",
      "duration": "5 mins",
      "category": "stretching",
      "intensity": "light",
      "description": "Simple neck, shoulder, and wrist releases while sitting."
    }
  ]
}

👉 2. Get Single Practice Details by Slug
• Method: GET
• Route: /api/movements/:slug
• Headers: None (Public)
• URL Params:
  - slug: "desk-stretch" (or any valid practice slug)
• Success Response (200 OK):
{
  "success": true,
  "data": {
    "id": "1",
    "slug": "desk-stretch",
    "title": "Desk Stretch",
    "duration": "5 mins",
    "category": "stretching",
    "intensity": "light",
    "description": "Simple neck, shoulder, and wrist releases while sitting.",
    "steps": [
      {
        "stepNumber": 1,
        "title": "Neck Rolls",
        "instruction": "Gently roll your head in a clockwise circle for 30 seconds."
      },
      {
        "stepNumber": 2,
        "title": "Shoulder Shrugs",
        "instruction": "Inhale and bring your shoulders up to your ears, hold, and release."
      }
    ],
    "totalSteps": 2
  }
}

• Error Response (404 Not Found):
{
  "success": false,
  "error": "Practice not found"
}

5. JOURNAL MODULE (Protected)
==============================

👉 1. Get All Journal Entries
• Method: GET
• Route: /api/journal
• Headers:
  - Authorization: Bearer <token>
• Success Response (200 OK):
{
  "success": true,
  "count": 1,
  "data": [
    {
      "_id": "670c5e3d1234567890abc001",
      "user": "670c5e3d1234567890abcdef",
      "title": "A page from today",
      "content": "Reflected on the project architecture and took a long evening walk.",
      "category": "daily reflection / diary",
      "dateText": "25 Oct 2026",
      "createdAt": "2026-10-25T10:30:00.000Z",
      "updatedAt": "2026-10-25T10:30:00.000Z"
    }
  ]
}

👉 2. Create Journal Entry
• Method: POST
• Route: /api/journal
• Headers:
  - Authorization: Bearer <token>
  - Content-Type: application/json
• Body:
{
  "title": "A page from today",
  "content": "Reflected on the project architecture and took a long evening walk.",
  "category": "daily reflection / diary",
  "dateText": "25 Oct 2026"
}
• Success Response (201 Created):
{
  "success": true,
  "data": {
    "_id": "670c5e3d1234567890abc001",
    "user": "670c5e3d1234567890abcdef",
    "title": "A page from today",
    "content": "Reflected on the project architecture and took a long evening walk.",
    "category": "daily reflection / diary",
    "dateText": "25 Oct 2026",
    "createdAt": "2026-10-25T10:30:00.000Z",
    "updatedAt": "2026-10-25T10:30:00.000Z"
  }
}
• Error Response (400 Bad Request):
{
  "success": false,
  "error": "Content is required"
}

👉 3. Delete Journal Entry
• Method: DELETE
• Route: /api/journal/:id
• Headers:
  - Authorization: Bearer <token>
• URL Params:
  - id: "670c5e3d1234567890abc001"
• Success Response (200 OK):
{
  "success": true,
  "message": "Deleted successfully"
}
• Error Response (404 Not Found):
{
  "success": false,
  "error": "Entry not found"
}
