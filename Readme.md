# Mindora Backend

REST API engine for Mindora—a mindful wellness application built with Node.js, Express, MongoDB Atlas, and Upstash Redis.

---

## Features

- **Passwordless Auth:** Email OTP via Nodemailer, Google OAuth 2.0, and instant Guest sessions.
- **Security & Limiting:** IP-based distributed rate limiting via Upstash Redis.
- **Mood Engine:** Daily mood tracking, monthly calendar queries, and yearly heatmaps.
- **Calm Corner:** Mindfulness exercise tracking and aggregated session statistics.
